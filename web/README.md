# QOUNT 前端

当前静态前端为 `web/app/`，由 FastAPI 提供只读数据和文件；主导航为资产、实盘、记录、研究。部署事实见 [current](../docs/current.md)，发布和回退见 [部署手册](../docs/vps-deployment-runbook-2026-10.md)。账户收益曲线与研究导航已于2026-10-16/17 UTC发布；完整研究运行仍留在Mac/WSL。

- 资产：真实钱包余额、USD-M USDT持仓与观测历史。余额变化不冒充收益，未映射到策略池的账户资产仍保留。
- 实盘：后端策略收据、实际持仓、保护检查及真实USDT合约账户收益曲线。显示最近运行、预计检查、下一入场时点及来源中的仓位风险。页面只读与后台自动执行分开。
- 记录：真实成交、收入和资金流；只有交易所订单ID精确关联的成交才显示策略归属。
- 研究：读取 `/research/*`，保留历史结果、暂停和封存研究。模拟流水从研究详情进入；关闭前向模拟不隐藏历史研究。名称和说明由来源配置提供。

`/account/performance`只读取真实权益历史与income库，扣除划转影响，以链式Modified Dietz近似计算收益；含手续费、资金费和未实现盈亏。覆盖缺失、观测时点含糊或钱包变化未对齐时断线，各段独立起算。卡片显示最近连续区间；不拼接模拟、不年化、不声称当前策略独立收益。

通用研究线按配置明确选择run；页面可切换完整实验、同窗叠加对照，并查看对应run的成交。页面选择不修改配置或实盘规则。

`/paper/*` 是另外的严格前向模拟查询，不替代研究目录。`web/site/`、旧read model和publisher仍有历史/运行消费者，本次不删除、不改变既有调度。

本地检查：

```bash
node --test tests/frontend/*.test.cjs
node --check web/app/app.js
node --check web/app/live.js
```

浏览器回归仅指向本地候选API，检查四个主页面、研究内部流水、窄屏、失败/乱序和只读请求；测试fixture不作为生产数据。

`tests/frontend/personal-system.browser.cjs`补充真实收益来源、实验切换/对照/成交隔离和接口失败检查；仍只允许本地候选地址。

USDT权益独立于其他保证金估值；极小额BNB等余额保留未估值提示，不抑制已取得的USDT读数。已有采集缺口保持断线，不回填。
