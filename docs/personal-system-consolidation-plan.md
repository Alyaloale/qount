## 定位检查与调整

本计划是个人系统整理与后续研究安排，服务于长期实盘风险调整后财富增长。账户真实、研究与生产分开、数据复用及结果隔离符合项目定位；本轮工程是owner明确要求的交付。但系统可用、回放一致和测试通过都不能证明策略有盈利优势，整理完成后不应继续以架构完整度代替策略研究。

本次检查修正三处偏移：后续优先回答净收益与风险问题；删减与current、部署手册重复的发布流水；复用组件按实际实验需要扩展，不安排全研究线迁移、统一认证或固定观察期。当前宏观只是有现成证据可继续拆解的研究对象，不获得长期资源优先权；ETF、A股、传统规则和机器学习仍按预期信息价值与成本比较。

## 产品范围

当前真实账户接入 Binance，研究保留 A 股、ETF、加密、宏观及机器学习。当前实盘场所不决定研究资产范围，也不把当前运行策略固定为唯一研究方向。

主导航为资产、实盘、记录、研究。真实记录由账户源提供，模拟持仓和模拟流水留在研究线详情。前端不访问交易所或提交订单，不再生成跨研究线等权模拟组合。

## 本轮实施计划（2026-10-16）

owner要求把优化方案落到代码并补齐实盘收益曲线。本轮保留FastAPI、SQLite、静态前端和脚本；不新增研究管理平台、登记服务或阶段审批。

1. **先修当前使用问题**：页面只读与后台自动执行分开；清除过时交接和简化1ATR文案；显示实际运行原因、时间与风险金额。包初始化按需加载旧兼容能力，账户观察不默认导入MiniTrend治理链。
2. **补真实收益**：以真实USD-M USDT权益观测和已采集income计算资金流调整后的累计损益及区间收益。明确账户范围、观测起点、采样频率和覆盖；不拼接回测、不回填不存在的历史、不将账户收益冒充当前策略收益。资金流覆盖或钱包会计关系不成立时断开曲线。完整资金费归属后才能给策略净损益，收益率另需本金边界。
3. **完成研究复用**：补齐数据、特征和结果的缓存身份，代码实际依赖变化必须失效；结果写完再发布。当前宏观1ATR接入共享结果目录，简化1ATR保留为历史对照。不同市场保留自身撮合与成本假设。
4. **接通实验查询**：各线使用`<line>/<run_id>/`，共享只读输入；所选实验由配置明确指定，不能按mtime选结论。曲线、摘要和成交来自同一run；保留其他实验供比较。
5. **整理历史代码**：删除内容重复的备份和无用副本；旧失败/冻结实验进入现有archive/legacy；保留独有实现、失败结果、模型和输入。先查源码/CLI/部署引用再删，不停止仍有消费者的publisher、observer和通知任务。
6. **验证与交付**：只跑受影响的账户会计、时点/成本、研究复用、历史一致性和前端检查。同步本文件和current的实际完成状态；本地实现与线上发布分开记录，不修改交易参数、订单权限或自动执行调度。

验证重点：入金不能制造收益；覆盖不足不能连出收益曲线；同输入重复运行复用；修改真实依赖或参数生成新run；选择旧实验不混入其他run的成交；已选宏观策略回放保持一致。

生产执行、共享E盘数据、冻结模型及历史结论保持现有边界。2027/2028交易日历已于10月18日单独验证并发布，原2026口径保持；日历维护不改变已授权策略参数或资金边界。

## 研究与模拟分开

复用 `config/paper-lines.json`，不另建登记系统：

- `display`：是否进入研究目录。
- `research_status`：`research / forward / paused / archived`，描述研究维护状态。
- `enabled`：仅控制前向模拟可见性，不控制研究结果是否保留。
- `sample_kind`、`presentation`：来源样本类型和页面研究说明，不授予订单权限。

`/research/*` 读取保留的研究结果与本线模拟记录；`/paper/*` 严格过滤启用、新鲜、可追溯的前向来源，保留真实市场与工具身份；Binance原生合约继续核对映射，ETF、现货及qfq代理不得改标成USD-M。10月22日owner明确要求恢复后，合格的多市场前向与旧历史分段展示。归档、暂停或缺源不把历史文件改写成有效前向数据。现有SQLite表名保留兼容，无需为改名重建数据库。

## 复用与隔离

公共行情以来源、标的、周期和数据版本区分；ETF代理与实际合约不可互换。`load_cached_history()` 可合并明确选择的旧小时缓存，检查重复冲突、缺口与资金费覆盖，不下载、不改写原文件，不为晚上市标的补造历史。

新实验默认写入 `state/research_runs/<line>/<run_id>/`，包含 `summary.json / nav.json / trades.json`。run身份包含输入哈希、代码和参数；同身份可复用，任一变化生成独立目录，已有结果不覆盖。各线只共享只读输入，不共享可写持仓、模型、最佳参数或输出文件。

CAGR按实际日历时长，Calmar使用年化收益/MDD。当前共享指标对不足一年样本不报告年化，短样本主要展示净收益、回撤和交易数；这项展示约定不成为其他研究开工的一年门槛，也不将短期表现外推为长期目标。不同市场保留适用的成本与撮合逻辑，不强行合并 A 股 T+1/公司行动与合约保证金/资金费。模型拟合缓存须区分训练窗口、预处理拟合范围、切分、参数与随机种子；目录隔离不使已消费历史变成独立OOS。
