# 加密趋势前提诊断（描述性，非 trial）

> **状态**：预登记（冻结于运行前）｜**日期**：2026-09-29｜**全局 trial 计数**：150（本诊断不增加）
> `research_only=true / orders_authorized=false / data_role=consumed_historical_discovery_pool`

## 1. 问题

C60 全样本 CAGR 约 50%，但 2025–2026 年接近零或为负。参数微调不回答根本问题：
收益到底来自哪里（整体 beta、择时、选币），这些来源在 2024–2026 年是否还存在。
本诊断只做分解与分年度描述，不评估新规则、不给 promote/reject 结论。

## 2. 数据与规则

- 数据：`state/research_runs/c60_cost_expectancy_v1/7495a6fbc649fd2d/closes.json`（data hash `1fa1b9037212`），不联网。
- 策略：`research_monthly`（Trial 150 = C60 v2），目标由 `c60_cost_study.target_path` 生成；分解在 0 bps（信号）上做，
  成本 = 信号年收益 − 25 bps 年收益。
- 年度：2021–2026（2026 截至 9-28）。

## 3. 指标

**A. 收益分解**（逐日可加，按年求和，单位为日收益之和）：
`r_strat = Ḡ·r_BTC + (G_t − Ḡ)·r_BTC + Σ w_i (r_i − r_BTC)`，
分别为静态 BTC beta、择时（仓位随时间变化）、相对 BTC 的选币。Ḡ 为全样本平均总仓位。另报各币种贡献。

**B. 信号有效性**（与策略无关，检验前提本身）：
1. 时序趋势：10 个币种合并，价格在 SMA20 之上 / 之下时次日收益均值之差（bps/日）。
2. BTC SMA50 系统闸门：闸门开 / 关时 10 币等权次日收益均值之差。
3. 截面动量：每个月末 90 日动量与之后 30 日收益的 Spearman IC，按年取均值与正值比例。
4. 趋势效率：每币 20 日 Kaufman 效率比（|净变动| / Σ|日变动|）年均值，10 币平均。

**C. 市场结构**：BTC 年收益、9 个非 BTC 币等权相对 BTC 的年超额、30 日收益截面离散度年均值。

## 4. 解读规则（运行前写定）

- 若 2024–2026 年 B1–B3 同时接近零或反号，而 2021/2023 为正：根因是市场结构变化（趋势溢价消失），
  调参无法解决，应停止在该宇宙上迭代趋势规则。
- 若 B 仍为正而 A 的选币项为负：根因是规则实现（选币方式）而非前提。
- 若收益主要来自静态 beta：C60 本质是"打折的 BTC 多头"，应与 BTC 持有的风险调整后收益比较，而非看绝对收益。
- 输出只写 `state/research_runs/crypto_trend_premise_v1/`（0600）。据此提出的任何新规则须另行预登记为 trial。

结论（按 §4 预写规则）：
1. **不是"趋势前提整体消失"**：效率比 0.22–0.25 各年稳定；截面 IC 在 2022–2025 仍为正；择时项 5/6 年为正。§4 第一条不成立。
2. **历史高收益来自少数爆发性事件**：选币项集中在 2021 山寨季（非 BTC 相对 BTC +505%，离散度 0.37）和 2023–2024 的 SOL；
   SOL + DOT 约占全期合计的一半。2022–2026 非 BTC 币种连续 5 年跑输 BTC，离散度降到 0.08–0.17，选币的机会集合明显收缩。
3. **宇宙有事后选择偏差**：10 币名单是 2026 年仍存活的大市值币，包含事后看最成功的 SOL，未包含 LUNA/FTT 等退出者；
   历史选币收益被高估，G6（剔除 SOL）只能部分缓解。
4. **成本是固定的，收益是间歇的**：成本每年 4.9%–13.4%（2022 起）不随机会大小变化；2025 年成本吃掉信号收益的 45%，2026 信号本身为负。
5. **C60 实质是低仓位（平均 35%）的 BTC 相关多头加间歇的山寨爆发捕捉**。在 BTC 主导、低离散度的状态下，
   预期前瞻收益接近 0，这不是闸门或候选参数能改变的。

对研究方向的含义（不在本诊断内检验）：
- 继续在同一 10 币宇宙上调趋势规则，边际价值低。
- 真正值得问的问题是**状态**：离散度 / 山寨相对强度是否能事前识别"选币有效期"。这需要把离散度作为预定义条件变量，
  预登记为新 trial，并使用未消耗数据（forward），否则只是事后解释 2021。
- 择时项较稳定，但仅靠 BTC 的低换手趋势暴露应和 BTC 持有的风险调整后收益比较，也须另行预登记。
