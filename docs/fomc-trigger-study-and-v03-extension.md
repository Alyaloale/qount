## 1. 方法

复现合同冻结口径的简化版本：对 2024-01 至 2026-06 共 20 次 FOMC 决议（决议 UTC 18:00/19:00），
在决议前 2 小时冻结前 72 根完成 1h K 的 H0/L0 与 1h ATR(14)，突破线 = H0+0.25ATR / L0-0.25ATR。
统计决议后 10 小时内（近似入场窗口）是否出现完成 1h 收盘在线外（= 1h 方向锚触发），
以及 D0（10h）、D+1（34h）、D+3（72h）在锚方向上超出突破线的最大有利/不利幅度（以 ATR0 为单位）。
未复现 15m 放量/实体/CLV/回踩确认，因此真实触发率会低于此处的锚触发率。

## 2. 结果

**触发率**：20 次事件中 11 次（55%）出现 1h 方向锚。叠加 15m 全套确认后，
实际可入场比例估计在 25–40%/次事件。**NO_TRADE 是常态结果，不是故障**——不触发的成本为零。

**效应大小（D0 有利幅度，ATR 单位）**：11 次锚中 7 次 ≥2.0 ATR（约可支撑 2R）：

```text
2024-07-31 short 3.58   2024-09-18 long 2.91   2024-12-18 short 4.51
2025-03-19 long 5.05    2025-05-07 long 3.61   2025-07-30 short 2.05
2025-10-29 short 4.00
弱锚（<1.5 ATR）：2024-11-07 0.73、2025-01-29 0.44、2025-09-17 1.21、2026-04-29 1.32
```

**关键模式——弱突破会反噬**：4 次弱锚中 3 次随后大幅反向
（2025-01-29 adv 8.0 ATR、2025-09-17 adv 6.3、2026-04-29 adv 7.4）。
"效应不够大"的事件恰恰是应该不做/被止损小额出局的事件；现有 2R 空间门 + 止损结构已正确处理它，
**不需要为小效应事件降低门槛，那是负期望方向**。

**"只做一天太短"——是的，对强突破而言**（D0 → D+3 有利幅度，ATR 单位）：

```text
2024-07-31: 3.58 → 11.93    2024-12-18: 4.51 → 12.55
2025-05-07: 3.61 → 16.81    2025-07-30: 2.05 →  7.89
2025-10-29: 4.00 →  9.33    2024-09-18: 2.91 →  6.85
（反例：2025-03-19 5.05 → 5.05 无延续；弱锚延长持有则全部恶化）
```

强突破（D0 ≥2 ATR）的主要利润在 D+1~D+3 才展开；当日上海 19:00 硬平仓平均砍掉过半的可得幅度。
弱突破延长持有全部变差。**延续持有必须以 D0 强度为条件，而不是无条件延长。**

## 3. v0.3 扩展提案（待预登记，不改变 v0.2 现状）

保持 v0.2 全部入场/确认/风险门不变，只把"上海 19:00 无条件全平"改为条件分支：

1. **弱分支（默认）**：19:00 检查点时未实现有利幅度 <2R → 按 v0.2 原样全平（历史上这些延续为负）。
2. **强分支（延续持有）**：≥2R → 不平仓，改为：
   - 止损上移/下移至保本（入场价 ± 成本缓冲）；
   - 启用 3×ATR0 吊灯 trailing（复用 MiniTrend 已验证机制），只跟完成 1h K；
   - 硬截止 D+3（事件后 72h）强制全平；
   - 期间禁止加仓、禁止反手，保护单始终为交易所原生 STOP_MARKET。
3. 风险预算不变（首笔 5U）：延续持有在保本止损后为"零新增风险、只让利润奔跑"。

诚实边界：n=11（含 15m 过滤后更少）、OKX 数据、单一资产、discovery 级、未做成本/funding 全复算。
7/30 canary 仍按 v0.2 执行；v0.3 须先写预登记合同 + 单测 + 用 Binance 数据复算后才可用于 9 月事件。
