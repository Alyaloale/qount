## 0. 现行合同冻结

观察期（2026-11-04 起至裁决）内不换池、不换权重、不加保险腿、不改再平衡节奏。杠杆档位（当前 2.0x）是 owner 风险偏好选择、非研究问题，owner 可随时调整但单独记录，不进入研究裁决。

## 1. 噪声带约定（判断基线）

- 单半年窗路径噪声：再平衡溢价符号 **±13pp**、拒单叠加 **±18pp/半年**（横盘窗研究 2026-11-03）。**单半年窗偏差不归因执行故障或机制变化，看 12 个月累计。**
- 一切对照使用**拒单语义回放口径**（era +478.2% / pre +3.8% / fwd +35.1%），不使用全成交头条（+550.7%）。
- 历史三窗（era/pre/fwd）已消费，只作预期锚点，不再作为任何新结论的证据。

## 2. 触发式复盘（任何时点；只触发复盘，不自动换 knob）

| 触发 | 阈值 | 告警级 | 动作 |
| --- | --- | --- | --- |
| 回撤预警 | 自部署峰值 MDD ≥ 50% | WARNING | 通知 owner，准备复盘 |
| 回撤超披露 | MDD > 57.3%（pre 窗压力上限） | CRITICAL | 强制复盘，owner 决定去留 |
| 可行性地板 | 权益 < 28U | CRITICAL | 复盘（腿转现金棘轮开始，27.5U 地板） |
| 深负漂移 | 滚动 12 个月 < −40% | CRITICAL | 复盘（超出两个预提负漂移半年窗） |
| 运行故障 | 连续 2 周期 BLOCKED 或看门狗 STALE | WARNING | 工程复盘，不改研究结论 |
| 执行背离 | 连续 4 周计划 delta 成交率 < 5% 且漂移带持续击穿 | WARNING | 执行链工程复盘 |

预提项（非触发）：平静横盘 ≈0%/半年属正常机制；温和负漂移段 −20~−35%/半年属预提区间内，不触发复盘。

## 3. 计划裁决（一次性，不逐项迭代）

- **裁决对象**：池（base11 / betaslim / div11）× 权重（等权 / 逆波动率）× 保险（无 / SQQQ 1/12），**一次性决定组合**（snapshot resolution_discipline：组合不回测比大小，防拟合）。
- **证据口径**：各候选在**同一真前向窗**的离线拒单语义重放，对照实盘实现值；6 个月窗（2027-05-04）为中间记录点，12 个月窗（2027-11-04）为计划裁决点。
- **采纳门**（满足全部）：前向窗内 MDD 不劣于现行，收益差 ≥ −18pp（不以超噪声带的增长代价换风险），且（MDD 改善 ≥ 10pp 或 Calmar 提升 ≥ 0.3）。6 个月窗提前裁决需差值超 2 倍噪声带。
- **否决门**（满足任一）：收益差 < −18pp 且 MDD 未改善 ≥ 10pp。
- **未定门**：其余情形继续积累前向，至 2027-11-04 再裁。
- **owner 偏好通道**：owner 可随时以风险偏好直接选定组合并记录于 [current.md](current.md) 即生效；**偏好选择与研究结论分开记录**，偏好不冒充证据。

## 4. 策略级证伪线

满足任一即 v3 机制被真前向证伪，进入重建（而非调参）流程：

1. 12 个月真前向（拒单口径）为负，且同期 EW-11 1x 同窗重放为正，杠杆维持机制负贡献超噪声带；
2. 连续两轮触发式复盘指向同一机制缺陷且无法由执行语义噪声解释。

## 5. 不做清单

- 不在观察期中途回测比大小挑组合。
- 不用已消费三窗论证任何"新"结论。
- 不因单半年窗回撤改合同。
- 不把执行语义噪声（±18pp）当 alpha 变化归因。
