## 0. 一句话结论

CRA 的核心"盈利引擎"是 **马丁格尔加倍补仓（Martingale DCA）+ 高杠杆（1–100x）+ 高循环次数（合约 5000）**，
外面套一层 EMA60/EMA10/振幅的开仓过滤。它每天"盈利几十刀"正是马丁的特征：**高胜率、小额盈利、把左尾巨亏藏起来**。
排行榜是**幸存者偏差**，配合点卡/激活码/邀请分佣/等级级差（类 MLM）变现，说明厂商收入来自拉新而非交易 edge。

对 qount 的价值 = 提取少量可测试的机制假设 + 一两个真正有用的风险规则；**同时把马丁、杠杆、幸存者营销记为反面教训**，
与 `research-advancement-roadmap.md` §10「当前不做」和跨线经验库一致。

## 1. 产品与变现结构（判断可信度用）

- 六所支持（Binance/OKX/Bitget/HB/Gate/Bybit），绑 API 托管下单；「资金托管安全无忧」话术。
- 变现：USDT 充值 → 买激活码激活机器人 → 点卡当手续费；**邀请分佣、团队等级级差分佣、推广奖励、红包**。

**判读**：变现依赖推广层级 = 强先验，"策略有效"不是主要卖点，拉新才是。任何收益展示按 T4 处理。

## 2. 策略机制拆解

### 2.1 现货策略
- 类型：马丁趋势策略 / 华尔街策略 / 激进策略。
- 开仓：挂单价（0=市价，或限定价如 BTC 65000 才买）、首单额度、**首单加倍**。
- 循环：单次 / 循环（最多 100 次）。
- **补仓（DCA/摊低成本）**：补仓次数（例 7）、补仓总金额（例 1280U）、补仓条件（跌幅比例 + 回调比例）、
  **防瀑布 2%**。
- 止盈：全仓 / 尾单 / 首尾；静态止盈 / **移动止盈**。

### 2.2 合约策略
- 类型：顺势(多) / 顺势(空) / 逆势稳健 / 逆势(激进)。
- **开仓指标（三选一）**：
  1. **MACD**：金叉死叉作为多空信号。
  2. **逆势**：以 EMA60 为基准线，**价在 EMA60 上方只做空、下方只做多**（反趋势），开仓时点由**振幅大小**决定。
  3. **顺势**：以 EMA60（大周期方向）+ EMA10（小周期时点）为准，**EMA60 上方做多**，开仓时点由 **EMA10 拐点**决定。
- 杠杆 1–100x；首单额度（例 5U）；循环次数（例 5000）。
- **补仓指标**：MACD（金叉死叉补仓）或 **EMA4 上下拐点**补仓；补仓次数（例 9）；防瀑布 2%。
- **补仓条件表（马丁加倍网格）**：第1单 1倍/差价3%/回调0.3% → 2倍/4%/0.5% → 4倍/5% → 4倍/7% → 8倍/9% →
  8倍/10% → 16倍/11%…… **这是倍投摊低成本，不是 alpha。**
- 止盈：全仓 / 尾单 / 首尾；静态 / 移动。
- **反向止盈**：金叉开多后未补仓且盈利时，出现死叉反向信号则清仓。
- **反向止损**：出现反向信号且亏损时清仓。
- 止损：比例 / 金额 / 价格止损（例 40%）。

### 2.3 TD 逆势指标（3-2）
- 非传统 TD9（触发太少），改为「连续涨跌 9/13 根」优化成 **震幅值**。
- EMA60 定大方向：**上方只做空、下方只做多**（fade）。
- 例：15min、震幅 4%，价在 EMA60 下方，若干根 K 累计涨 4% → 建空（反向）；5min、震幅 2%，EMA60 上方累计涨 2% → 建空。
- **重置规则**：连涨过程中出现一根阴线则重新计震幅（反之亦然）；穿越 EMA60 一律看收盘价。

### 2.4 EMA 顺势指标（3-2）
- EMA60 大周期定方向，EMA10 小周期定时点。
- 周期映射：小 5m→大 30m、15m→1h、30m→2h、1h→4h 的 EMA60。
- **EMA60 上方只做多、下方只做空**；确认方向后，EMA10 **下拐点(∧, K1<K2>K3)建空**、**上拐点(V, K1>K2<K3)建多**；移动止盈出场。
- 备注：EMA60 在 K 线下方时不建多单（方向门），反之不建空。

## 4. 可吸收的东西（正向）

1. **防瀑布规则**：在补仓/加仓逻辑里加"短时急跌暂停加仓"是合理的执行风控，对应 R8/危机状态；把它形式化为
   `crypto_vol_crisis_state_v1` 的一个确定性 RiskMultiplier 触发器候选（须与已失败 price-only vol scaling 区别）。
2. **反向信号退出**：信号翻转即平仓，是干净的规则化 exit，值得作为退出/换手对照实验（须计成本）。
3. **EMA60 regime × EMA10 拐点**的显式多周期合同：作为 `multi_speed_trend_v1` 已拒绝结构的一个"厂商版本"存档，
   证明这类结构在零售侧也只是包装，不是新机制——强化"该 family 关闭"的结论。
4. **振幅重置**这种路径依赖的衰竭度量：作为一个 price-only 特征想法登记，优先用在 breadth/vol 状态输出而非直接方向。

## 5. 必须拒绝/警惕的东西（反向）

- **马丁 = 假盈利曲线**：高胜率小盈利掩盖左尾，"每天几十刀"正是它的外观；一次极端行情吃掉数月利润甚至爆仓。
- **杠杆 + 高循环**：把左尾放大到清算级别，违反本项目 effective gross ≤1、no-short、无杠杆增益硬边界。
- **无成本/无回撤/无样本/无 PIT 的收益展示**：正是"gross 正 ≠ net 正"的成本墙；不计 funding/fee/滑点/尾部。
- **MLM 变现**：厂商 edge 在拉新不在策略，收益叙事按 T4 归档。
- **API 托管**：第三方托管 API 有资金与密钥风险，与本项目密钥隔离/单一生产真相纪律冲突；不接入。

## 7. 给 owner 的直话

想靠这类机器人"每天稳定盈利"是马丁格尔的心理陷阱：你会看到几周甚至几个月的顺滑正收益，然后一次插针把本金端走。
它能提供的真正养分很少——一条"急跌别加仓"的风控直觉、一个"信号翻转就走"的退出想法，其余都是本项目已经证伪或明令
不做的东西（马丁、杠杆、扩币、幸存者营销）。把它当反面教材比当收益模板更有价值。
