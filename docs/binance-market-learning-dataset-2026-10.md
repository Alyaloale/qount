## 市场结构V3与固定周期截断修复（2026-10-31，离线）

本轮验证确认，旧V2把信号后的单一终点状态当作持仓窗口标签，会截断短状态并把窗口内切换误写成终点状态。币种趋势结构的中位连续段约3根K线；五根后仍保持同一趋势约55%～59%，收缩状态约25%，严格轮动在五根终点几乎没有同类延续。因此固定五根不是所有状态都适用的自然预测周期。

V4进一步输出“状态＋持续时间”：状态头给出未来窗口的六类结构概率，持续时间头给出从当前阶段开始还能连续保持多少根K线的分布，分为1至9根和10+根。持续时间标签使用未来十根内的连续段，成熟时间按十根终点计算；它回答阶段寿命，不把不同持仓窗口重新混成不同的寿命定义。两头暂不拟合稀疏的联合状态×时长模型。

V3将结构定义拆为六类：`uptrend`、`downtrend`、`rotation`、`compression`、`low_efficiency_chop` 和 `transition`。`transition`表示数据充分但方向、效率、斜率或边界条件混合；`unknown`仍只表示数据不足。`rotation`扩大为有明确双边触及、箱体包含和中线穿越证据的结构描述，但不自动授予区间策略权限。六类之间无重叠，事件和风险仍独立记录。

监督目标改为实际计划持仓窗口内的多数结构：窗口内最高占比低于60%时标为`transition`，不再由最后一根K线强行决定。研究同时评估1、3、5、10根窗口。修复后五根窗口的固定浅树结果如下；不同标签定义不能与旧V2准确率直接作绝对比较：

## 状态转移与剩余寿命模型审查（2026-10-31）

按方案执行第一版半马尔可夫式离线实验：每个状态段生成当前状态、已运行根数、后继状态、剩余根数和右删失标记；分别训练下一状态头和持续时间头，不拟合稀疏的状态×时长联合类别。输出包括后继状态概率、1至9根/10+持续时间概率、生存概率和预计剩余根数。

结果不支持接入策略：币种16个时间外折、3,259个状态段，后继状态准确率42.53%，低于历史后继众数基线48.08%；ETF代理12折、4,118个状态段，准确率46.49%，低于基线56.54%。持续时间期望MAE币种2.96根，略优于历史分布基线3.01；ETF代理3.18根，略差于3.15。输出结构和成熟时间验证通过，但没有稳定预测增量。完整报告见[状态转移与持续时间验证](../state/research_runs/market_regime_temporal_v1_20261031_final2/report.md)。下一步应先按状态段做转移稀有度合并和概率校准，再考虑更复杂时序模型。

### 为什么逐根转移模型低于基线

原始训练将一个状态段的最终后继状态复制到段内每一根观测。例如一个持续10根的上行段，第一根和第九根都被要求预测同一个后继，但两者距离转换点完全不同。历史后继众数对这种重复标签天然稳定，树模型却同时面对状态、年龄和结构混合目标。按状态和年龄拆分后，模型在币种和ETF各年龄段仍低于众数基线；这不是简单增加网络容量能解决的问题。

只用每个完整状态段最后一根作为边界预测样本后，诊断模型准确率约61.99%/62.10%，高于边界后继众数基线53.10%/54.79%。随后已统一随机种子并正式重训V2；正式主评估为币种53.07%对53.10%、ETF代理52.54%对54.79%。这证明标签复制是主要退化来源，但边界模型在完整滚动评估中尚未形成稳定增量。持续时间头的改善很小，不能替代边界转移模型。诊断结果见[时序诊断报告](../state/research_runs/market_regime_temporal_v1_20261031_diagnosed3/report.md)。

V2重新定义了数据和标签：`next_state`只在完整状态段最后一根定义，状态段内其他行只进入剩余寿命任务；右删失状态不作为已结束转移。币种16折边界转移准确率53.07%（基线53.10%）、平衡准确率27.86%；ETF代理12折52.54%（基线54.79%）、平衡准确率32.72%。剩余寿命MAE币种2.96根对基线3.04、ETF3.18对3.17。标签语义和训练时钟已修复，但预测增量仍不足，不接入策略路由。完整报告见[时序V2重训](../state/research_runs/market_regime_temporal_v2_20261031_final/report.md)。

## 当前状态定义：四种明确环境＋结构未明拒绝类（2026-10-31，V2）

**已将主研究标签从方向/波动/短暂事件混合分类，改为结构互斥的五类输出。模型预测计划交易的最后一根持仓K线环境：币种信号后延迟两根入场、持有五根，目标为信号后第6根；ETF下一交易日入场、持有五根，目标为信号后第5根。** 当前事件和风险独立记录，不覆盖环境标签。`unknown`仅表示数据不足，不作为可监督市场状态编造概率。旧十一类数据、模型与回放完整保留，禁止把旧概率直接改名为新概率；V2推理通过`market_regime_v2` schema拒绝旧工件。下方旧映射及实验均为历史对照。

| 模型环境 | 单一结构特征与固定定义 | 机械相容策略 |
|---|---|---|
| `uptrend` 上行趋势 | ER20≥0.30，方向连续确认，价格/EMA20在EMA50上方，EMA50五期斜率≥0.15ATR。 | 回调企稳做多；当前同向突破已确认时采用突破做多。 |
| `downtrend` 下行趋势 | 与上行严格镜像，斜率≤−0.15ATR。 | 反弹受阻做空；当前同向破位已确认时采用突破做空。 |
| `bounded_rotation` 双边往返区间 | ER20≤0.25、均线漂移小；以此前第40至21期形成的固定箱体检验最近20期，边界漂移≤箱宽15%、至少90%收盘留在箱内、当前也在箱内；两边各至少两次间隔到达，中线至少穿越三次，箱宽2～10ATR，近5/20期振幅比≥0.65。 | 箱体边缘拒绝后反转至中点；假突破须当前已失败且回到相应箱体边缘，目标仍为箱体中点。 |
| `compression` 波动收缩 | ER20≤0.25、相对波动率<0.75、近5/20期振幅比≤0.55。 | 等待释放；不把收缩直接当反转入场。 |
| `unresolved` 结构未明 | 不满足上述明确结构；ER及振幅缓冲区域也归入拒绝类。 | 不授权新仓。 |

四种明确结构在定义上互斥：趋势/非方向状态使用ER间隔，区间/收缩使用振幅比间隔，不通过优先级掩盖冲突。未明是拒绝类别，不能声称其包含一种已识别的稳定经济机制。固定阈值是可证伪描述假设，未按本轮收益搜索，不等于市场存在已获外部认证的五种自然真值。

突破观察、突破确认、突破失败独立保留原事件方向/边界/观察时间；失败不回写到突破开始时。冲击/冷却和高波动独立作为风险标记：前者阻止新增仓，后者不改变方向或箱体类别。本轮未新增自动风险缩放，以免混淆分类效果。概率通过70%后还要求当前结构一致、事件相容和原入场形态成立；相反方向的确认突破、尚未确认事件均不能触发不相容策略。已有仓位仍按原退出规则管理。

## 研究判断

需要同时保存三个不同层次：**经济身份、行为风格、当前行情阶段**。例如XLE经济上属于能源企业权益，在某个时期可以表现为弱股指联动；SOL可以在高波联动与高波深回撤风格之间变化。不能把“这个标的是哪个类别”直接等同于“现在应该做多或做空”。

当前证据支持保留简单概率/几何基线，并将精简方向树、几何加相对波动率修正作为离线研究候选。98字段增补版的89项合格输入已实际训练，全量加入未改善预测；类别/状态细编码/动态行为簇也未提供稳定额外增量。续轮原因定位发现过拟合及几何模型的相对波动率条件偏差，低维修正已有探索性改善，但2026币种样本仍有退化，尚非通用交易优势。小型MLP尚未优于树和几何基线，不能据此否定所有序列网络。RL适合以后研究有仓位记忆、成本和风险预算约束的连续操作，目前尚缺完整环境，未启动训练。

## 退化原因与结构化优化（续轮）

owner要求分析原因并优化。新增[原因定位与优化](../state/research_runs/market_probability_optimization_20261030/report.md)448次拟合、[相对波动率来源消融](../state/research_runs/market_range_offset_ablation_20261030/report.md)56次拟合，总计504次、约89秒单线程CPU；没有新增下载或扩大NN。只优化未来5期方向/区间，其他目标沿用首轮判断。七经济研究组、四行为簇、十二状态/十四编码不变。

### 原因与证据

1. **训练拟合改善，跨时期泛化退化。** 配对折均按测试行数加权汇总，币种方向训练Brier旧树0.49059→增补0.40587，未来却0.65356→0.66849；区间训练0.28274→0.26808，未来0.34704→0.35968。2023首折方向728行仅104个不同决策时点，宏观向量在七币间共享，模型输入124→214列。行数不能当作独立宏观样本数，这是过拟合和历史关系不稳定的证据，不是数据越多必然越差。
2. **部分上下文关联缺乏稳定性。** 只在过去训练集内按日期整体置换宏观向量，保持同期资产共享关系；币种区间反而比真实上下文增补树少0.01084 Brier，季度簇95%区间[-0.01877,-0.00279]。这是单种子诊断，不能推导宏观长期没有经济作用。
3. **几何模型遗漏了波动率条件偏差。** 在1,180条币种区间预测中，以固定相对波动率阈值0.8/1.2分组：低组403条实际保持62.03%、几何预测70.70%；高组262条实际88.17%、几何预测71.20%。ETF低组189条为50.26%/63.62%，高组160条70.00%/60.22%。同样的标准化边界距离，未来结果还受当前波动率相对历史位置影响；这支持条件修正，不证明唯一经济机制或全阶段因果规律。
4. **错误自信与方向辨识需要分开。** 币种MLP方向ECE约0.194，成熟预测收缩后约0.008，Brier0.73735→0.64112；平衡准确率却37.07%→33.53%。概率收缩主要抑制不可靠专家，不能称为方向信息同步增加。Brier也同时包含校准与辨识，不能代替全部校准诊断。
5. **缩短窗口、统一加大正则不是通用修复。** 最近三年旧特征树在币种/ETF区间Brier升至0.35440/0.43479，均弱于扩展窗口。深度1、2叶、L2=50的强正则改善方向概率，但币种区间退至0.37029，出现欠拟合；不同任务不共用一个最强正则配置。

```text
relative_volatility = log(sigma20 / median(up to252 strictly prior sigma20))
logit(p) = logit(p0) + b0 + b1 * standardized(relative_volatility)
```

固定把参考改为严格先前63期sigma20中位数，改善2026但损失早期效果；增加正负斜率、低波持续交互、365天半衰期的训练样本权重，都没有稳定超过原252期简单模型。近期权重归一到训练行数以维持L2尺度，预处理仅用过去训练数据。

### 收盘事件与盘中路径必须分开

同一批区间样本：币种收盘保持72.54%、盘中高低点保持56.95%，184条收盘保持但盘中越界；ETF分别60.08%、51.62%，差60条。这不是旧标签计算错误，而是目标含义不同。当前概率不能解释为未来五期不会触及边界或止损，ETF高低点仍为调整价代理。

时钟检查还发现：币种决策在日线结束后60秒，下一根日K高低点已包含这60秒内的价格。上述盘中统计只描述五根日K窗口，不能充作严格决策/成交后的风险标签。已有收盘目标不受影响；若训练可执行盘中越界/止损模型，需要分钟等细粒度数据剔除决策前区间，并按真实成交时点建模。ETF现金代理会话按当前映射无此60秒重叠，但也不是Binance原生连续合约路径。

### 时点问题的处理与来源验证

复用三份小时现货/永续缓存中的原生合约小时线，以及已有三币各35天的分钟ZIP，仅读取用于日界线细化的首小时。共912个小时聚合日与原日线OHLC逐值一致；63个分钟聚合小时也与小时OHLC逐值一致。没有下载新数据或填造价格。

即时路径定义为`[known_at,known_at+120h)`，其中`known_at`为日线完成后60秒。完整小时的高低点可证明越界或保持；首尾部分小时只有在窗口内可定位端点、或分钟覆盖充分时才给确定标签，否则标为-1。另设下一整点开始的120h窗口，距决策59分钟，完整小时可精确标注。标签成熟保守等整个末小时完成后再加60秒，不能把事件结束时点误当作数据已经可用。

得到529条完整路径，27条缺五天覆盖先排除；分钟细化66个边界小时。当前529条即使用小时证据也都能确定0/1，没有边界不确定；与该批样本原日K诊断标签一致，不能将时点修正本身宣传为准确率提升。新机制保留对其他样本返回“不确定”的能力，而不是假定每次都能定位极值。

目标价格边界为闭区间，触及但未越过仍算保持；当前是交易价OHLC事件，不是标记价格止损、不含盘口/成交/费用。连续几何基线由吸收边界热核积分并对等待期价格不确定性积分构造，只是近似，不能宣称真实价格服从Brownian过程。[公式来源](https://www.ma.imperial.ac.uk/~pavl/PavliotisBook.pdf#page=86)。

## 机器学习、神经网络与强化学习的分工

机器学习是总类，神经网络属于其中一种监督学习方法；强化学习则围绕动作如何改变未来奖励建模。不能把三者视作相互排斥的三个选项。

| 方法 | 适合的问题 | 本轮结论 |
| --- | --- | --- |
| 聚类/行为表征 | 哪些历史行为相似，标的风格是否改变？ | 已执行四类历史聚类；作为解释/诊断，增加聚类特征未得到稳定预测增量。 |
| 概率/几何基线 | 已知波动和边界下，区间维持是否本来就容易预测？ | 已执行固定零漂移高斯路径基线，解释了区间任务的大部分提升。 |
| 逻辑回归 | 特征是否有简单可复现的概率关系？ | 作为监督基线保留；本轮新增特征没有带来稳定方向优势。 |
| 树模型 | 非线性阈值、波动/距离/阶段交互 | 区间任务比频率基线改善；对更强几何基线的额外增量仍未稳定。 |
| 小型MLP | 特征非线性组合与表示学习 | 32→16隐层、固定40轮、三个种子实际运行；未优于树/几何，不扩大网络规模凑结果。 |
| GRU/TCN等序列网络 | 同一状态如何形成，变化路径有无增量？ | 日线序列索引已具备，尚未训练；应先与相同窗口的简单滞后特征对照。 |
| RL | 有当前仓位、成本、资金费和风险记忆的操作序列 | 当前未训练，数据集尚不是完整交易环境；适合以后检验目标敞口/加减仓策略。 |

绝不能让神经网络把均线规则产生的当期标签学到很高准确率，再称为未来判断可靠。本轮监督目标均来自后续可观察结果，状态与类别仅作当时已知输入。

MLP固定资源上限不代表训练已数值收敛，也不足以否定所有神经网络。所有填补/缩放只用训练数据，关闭随机验证划分和测试早停。参考[MLP官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.neural_network.MLPClassifier.html)、[聚类评价说明](https://scikit-learn.org/stable/modules/clustering.html)。

## RL何时有研究价值

RL可以在不依赖独立分类器的情况下端到端学习，但当前owner的顺序是先建立可信市场模型，因此不借RL跳过这一问题。更合适的接口是：

- 状态：市场信息/概率、经济类别/风格、当前仓位、现金、权益/回撤、风险预算、资金费和执行条件。
- 动作：目标敞口；空仓、部分持仓、加仓、减仓、维持是目标与当前仓位比较后的结果，而非脱离当前持仓的固定按钮。
- 奖励：实际扣成本后的财富增长，并按研究目标检验回撤/尾部约束；费用若已从账户扣除，不在奖励中再重复扣费。
- 环境：严格的决策/成交时钟、实际资金费、离散数量、价差/滑点、跳空/止损和部分成交、账户会计。当前日线标签没有这些完整机制。

因此当前不运行PPO/SAC或大规模GPU训练。可先在可信执行环境中比较一个简单仓位规则与一个最小RL候选，回答“动作序列是否改善净增长/回撤”，而不是奖励它提高分类正确率。参考[RL的状态、动作、奖励和策略](https://spinningup.openai.com/en/latest/spinningup/rl_intro.html)。
