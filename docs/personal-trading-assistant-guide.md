# 个人资产管理交易系统研究指南

> **状态**：active｜**权威**：个人策略研究与开发方法；遵循 [AGENTS.md](../AGENTS.md)｜**最后更新**：2026-10-15
> **TL;DR**：以长期实盘风险调整后财富增长为目标，用小实验寻找扣费后有价值的策略；资产数量、频率和模型复杂度由证据决定。

## 一、目标与策略选择

QOUNT 是服务个人账户的个人资产管理交易系统，覆盖资产分析、研究、组合、风控与授权执行。ETF 均线择时研究（`personal_assistant`）是一条普通研究线。优先评价净 CAGR、最大回撤、Calmar、跨市场阶段与时间窗口的稳定性，再结合资金规模、可交易单位、流动性、操作负担和计算成本作选择。净年化 20% 等数字可以作为探索目标，不能靠挑窗口、隐藏回撤或反复调参凑出。

个人账户可以持有现金、集中持仓、快速切换策略，也可以通过分散化降低风险。集中度、资产数量、行业暴露、换手率与杠杆均需比较其实际效果，不把某种账户结构预设为最优。

2026-10-11 的 1–3 只核心资产与年换手 <0.5x 属于当时助手方案的设计目标；现行 AGENTS 不把它们设为全项目限制。正在执行的具体任务、冻结参数与停止决定仍以 [current.md](current.md) 为准。换手应报告单边／双边定义和名义成交额，不能从交易笔数推定达标。

## 二、可检验的研究方向

| 方向 | 最小实验可以回答的问题 | 主要比较项 |
| --- | --- | --- |
| 趋势、择时、动量与反转 | 信号是否改善相同窗口和成本下的净收益／回撤 | 买入持有、简单规则、延迟执行与成本压力 |
| ETF 轮动、跨资产配置、波动率目标 | 现金、债券与权益切换或风险缩放是否有净价值 | 静态配置、同风险暴露、换手与尾部损失 |
| 个股质量、红利、低波与多因子 | 新信息是否在决策时可得，并提供增量 | 时点股票池、财报版本、行业暴露和执行限制 |
| Transformer、表示学习与序列预测 | 新表示是否提取稳定的预测信息 | 简单统计／线性基线、特征消融、跨种子与跨期表现 |
| RL 与策略学习 | 奖励、状态和动作是否改善真实成本下的决策 | 规则策略、相同状态输入、费用与动作空间消融 |
| 集成、专家混合与状态识别 | 不同模型是否有互补信息 | 单模型对照、权重稳定性、计算和维护成本 |

这张表提供假设方向。某个实现失败不能代表整个方向失败；复杂模型暂时优于基线也不能代表研究完成。明确封存的麒麟、币安合约等实现，以及其他冻结线路，不从本表获得恢复权限；原结论和证据入口见 [研究线导航](research-lines.md)。

## 三、从问题到最小有效实验

1. 明确机制和预期变化，例如“费用惩罚错位使 RL 过度换手”，而不是笼统要求提高收益。
2. 复用现有数据和代码，选一个能区分原因的对照：固定数据与切分，仅改变奖励中的费用项。
3. 在合理预算内运行，检查净 CAGR、MDD、Calmar、换手、成本与不同阶段表现；记录失败和计算开销。
4. 根据结果决定修复、消融、扩大样本或结束该实现。重要候选再做样本外、参数邻域及随机种子复核。

不要把每次探索升级成长篇立项合同，也不要无假设地扩大 GPU 搜索。已有模型变差时先区分过拟合、目标错位、费用错误、市场依赖、无效特征、动作限制和时间泄漏。对研究结论持独立判断，用实验区分解释。

## 四、数据、交易与评价底线

- **因果时钟**：区分信息发布／可用、决策、提交和可能成交。完整收盘信号在收盘后确认、下一可交易时点尝试执行；盘中预览不冒称正式收盘信号。
- **来源适配用途**：当前候选名单需要决策时的身份、价格、流动性和来源；历史回测需要对应时点的股票池、财报与执行资料。缺失影响某一结论时限制该结论，不要求先补完无关历史档案。
- **执行和成本**：计入适用佣金、税费、价差、滑点、冲击、成交单位、流动性和融资成本。止损线是触发规则；受阻退出、缺价和跳空须进入模拟，不假定阈值价成交。
- **收益身份**：价格指数、复权代理、现金总回报和真实账户分开；分红不可重复计入。000300 不能替代 510300 的可交易行情，份额拆分要同时衔接信号价格和持仓单位。
- **可比评价**：策略与基准采用一致窗口、预热、现金及成本口径；完整披露初始规模、净收益、回撤、年化方式、样本属性与限制，不只展示最优窗口。
- **模型验证**：按时间切分，预处理只用训练信息，适用时隔离重叠标签。测试集被用于选模型后不再是独立检验；具体冻结样本边界见 [holdout.md](holdout.md)。

## 五、研究、个人助手与生产衔接

```text
合格数据 → 因果特征／模型／规则 → 离线回测与消融 → 候选证据
                                    ↓
                         无订单信号、风险状态与确定性日报
                                    ↓
                         本地前向记录／只读看板
```

研究可以输出模拟权重、风险预算和虚拟交易，默认 `research_only=true / orders_authorized=false`。训练模型与研究 Agent 的能力不受日报 LLM 的只读输出合同限制；运行中的日报／情报 LLM 仍不能直接改真钱仓位、订单、live 参数或风控。

助手先帮助用户看清数据时点、规则状态、成本、风险与未知项。回测与每日记录应共享核心规则和状态机；数据未知不能生成有效交易建议。半自动和全自动可作为后续形态，生产下单与服务变更按已有明确授权推进，离线结果不自动授予权限。

五个交易日的本地记录只能验证工程连续性，不能证明长期盈利。具体当前进度和下一步集中维护于 [current.md](current.md)，不在指南重复任务流水。

## 六、执行与交付

按 [项目规则](project-rules.md)选择验证深度：探索运行小实验；候选补可复现与样本外证据；生产候选再验证执行约束、故障与风险。无关测试失败不能替代当前问题判断，局部测试通过也不能声称全系统通过。命令见 [本地开发](operations/local-development.md)。

Mac 做策略设计与轻量验证，WSL 做 CPU/GPU 重计算，E 盘保留完整数据与不可变工件；先复用缓存，再按信息价值扩大投入。凭据保持本机授权边界和 `0600`，不传 WSL／E 盘。主机细节见 [运行手册](operations/host-runbooks.md)。

交付说明实际改动／假设、实验条件、结果、验证范围和下一项最有价值的实验。保留原失败与旧版本；不把计划、代码实现、执行成功、测试通过和盈利结论混为一谈。
