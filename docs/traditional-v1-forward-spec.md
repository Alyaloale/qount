# Traditional V1-G1 Forward Testing Specification

## 1. 策略定性 (Strategy Definition)
**状态**: 冻结 (Frozen) - 历史候选 (Historical Candidate)
**评级**: 历史经济优势已形成，统计Alpha与前向持续性未确认
**核心逻辑**: 以半导体和科技为主要收益来源、通过跨板块动量轮动降低尾部风险的策略。

## 2. 核心执行规则 (Execution Rules)
- **信号资产**: 对应的 1倍 底层ETF
- **执行资产 (Universe)**: 7只 3倍杠杆 ETF (TQQQ, SOXL, FAS, CURE, URTY, DRN, ERX)
- **动量窗口**: 63个交易日收益率
- **选择数量**: Top 1
- **信号生成时间**: 每月最后一个交易日收盘后 (End of Month Close)
- **执行成交时间**: 信号生成后的下一个交易日开盘 (T+1 Open)
- **风险预算**: 组合总净值的 10% 暴露于 Top 1 资产
- **底仓资产**: 组合总净值的 90% 暴露于 BIL (1-3月美债)
- **调仓逻辑**: 仅当新 Top 1 与原 Top 1 不同时，产生切换交易
- **成本口径**: 至少 20 bps 压力测试口径 (含滑点与佣金)
- **过滤器**: 无 A(绝对动量)、P(价格过滤)、S(斜率过滤)、Z(高位止盈)

## 3. 前向对标基准 (Forward Benchmarks)
从 **2026年8月3日 (星期一)** 开始，前向引擎必须严格同步计算并记录以下 4 条曲线的净值：
1. **B0 (基础科技基准)**: 90% BIL + 10% TQQQ
2. **B1 (高风险基准)**: 90% BIL + 10% SOXL
3. **B2 (最强竞争基准)**: 90% BIL + 5% TQQQ + 5% SOXL
4. **G1 (主测试策略)**: 63日 Top1 轮动策略

*注: G1 的首要验证目标是，在未来 12-36 个月内，能否保持与 B2 接近的收益，同时实现更低的最大回撤和更高的夏普/卡玛比率。*

## 4. 引擎开发与迭代纪律 (Engineering Discipline)
- **绝对冻结**: 此版本规则、数据源映射、处理逻辑不可更改。
- **版本隔离**: 任何未来对资产池、参数、逻辑的修改，必须新建策略版本号（如 V1.1, V2.0），旧有前向曲线必须继续按原规则运行并留存，绝不允许回写覆盖历史净值。
- **预注册评估节点**: 前向运行满 12次 (初步诊断)、24次 (中期评估)、36次 (正式确认) 月度调仓后进行绩效审查。
