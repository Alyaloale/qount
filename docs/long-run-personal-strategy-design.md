## 一、先诚实总结：你的研究历史证明了什么

148 次 formal trial 加上 line A/B/C/D、L1–L6 的系统性证伪，结论高度一致，这些是**资产**而不是失败：

**已被反复证伪、不应再投入的方向：**
1. **短周期择时 alpha（分钟~小时级）**：line A 的 setup/AI 链路、5m GBDT、4h xs_mom、
   1d TS-MOM、grid、RV、X4 短线——post-cost edge 全部贴 0 或为负。成本墙（taker 0.05%×2 + 滑点）
   吃掉了个人级别能捕获的全部短线信号。
2. **微观结构 / 高频信息**（L6）：IC 真实存在但可操作档净负——**延迟墙**，个人基础设施无法跨越。
3. **跨所套利 / carry**（L4）：毛价差真实（+7.4%/yr）但 break-even 2.7bps/腿、需要 ~93% maker 成交率
   ——**执行墙**，需要多所账户 + maker 基础设施。
4. **信息源新 alpha**（L3 稳定币/链 TVL、options-DVOL、链上 vintage、宏观 H4.1 直接择时）：
   要么 IC 证伪，要么广度不足（G0 有效广度 <2），要么 point-in-time 数据根本不存在。
5. **参数救援**：所有"调阈值/加 overlay/换 regime 分类"的尝试（risk tier、regime overlay、
   stop latch）几乎全部在 2025-2026 弱段恶化——**过拟合墙**。

**真正站住或部分站住的（这是设计的地基）：**
1. **L1 跨资产趋势**：S1 广度通过（有效广度 2.97）、S2 趋势 REAL 且 robust——这是全部研究中
   **唯一一次"真实正 edge"判定**。失败点只是工具：retail ETF 做载体时净 Sharpe ~0.4，
   卡在 0.5 门槛下。结论是"edge 真、载体钝"，不是"edge 假"。
2. **MiniTrend UM base（TOP3 long/cash 日线趋势）**：归因已明确它**不是 alpha，是低 beta 的
   牛市风险包装器**——全窗 +66.5%/Sharpe 0.90/maxDD 17.3%，对比 BTC 1x maxDD 78.9%。
   它做不到"每段都赚"，但把持有 crypto beta 的破产风险砍掉了 3/4。这就是它的真实价值。
3. **Funding Veto 成本机制**：唯一通过全部预登记历史门的机制（+0.44pp 来自真实 funding 节约）
   ——证明**成本工程是真实、可复制的收益来源**。
4. **事件 / 被迫流方向**（FOMC、TradFi 周末收敛、清算 forced flow）：工程链路已建好，
   证据尚弱（周末收敛 P(mean>0) 仅 71%），但这是"谁被迫交易"框架下唯一还没被证伪的 alpha 类别。

**一句话**：你已经用两个月和 148 次 trial 证明了——个人条件下，**可持续的收益来源不是预测，
而是：(a) 有纪律地持有风险溢价并控制回撤，(b) 成本工程，(c) 少量事件性被迫流机会。**
这恰好和学术/业界对个人交易者的共识一致。你不是没找到圣杯，是证明了圣杯不在你能去的地方。

## 二、设计原则（从证伪记录直接推出）

1. **不再买"预测"，只买"风险溢价 + 凸性"**。长期收益主体来自持有 beta，策略的工作是
   管风险（趋势闸 + ATR 止损 + gross 上限），不是猜方向。
2. **周期只能是日线及以上**。h6 以下全部撞成本墙；你唯一的真 edge（L1 趋势）本身就是周/月级。
3. **广度是免费的午餐**：加密内部有效广度只有 1.4–1.7（G0 反复阻断横截面），
   但加密×美股×债×商品的跨资产面板广度 2.97 已实测通过。**分散必须跨资产类，不能在币圈内部做。**
4. **成本工程与策略同权重**：低换手（deadband 35% 已验证）、funding 感知、能 maker 就 maker。
5. **事件仓位单列小额**，用"谁被迫交易"检验，一次性机会用 alert + 手工，不塞进 daemon。
6. **每条 sleeve 独立预算、独立证伪、独立停止**，复用你已建成的 registry/allocator/authority 架构
   ——这套架构本身就是为这个组合形态设计的（Phase E 的 multi-sleeve 已过本地 fixture）。

## 三、目标组合：三层 sleeve（建议全账户视角）

### Sleeve 1 — 核心：跨资产趋势/风险管理的 beta 收获（占 70–80% 资金，预期贡献大头）

- **美股/ETF 部分**：先采用独立预登记的 `SPY 60% / TLT 40%` 被动配置；L1-S2 趋势载体已终止，不能再称为
  `REAL+robust`，也不得复用其代码、结果或参数做新的个人账户结论。
  - 被动配置只处于 research-only；需要重新研究趋势时，另建最小合同和独立验证，不从终止线继承资格。
- **加密部分**：沿用 MiniTrend UM base v0.2 的历史定位——TOP3 long/cash、日线、1x isolated、
  3xATR 吊灯、35% deadband、gross≤1，外加已验证的 funding veto 做成本闸。
  - 诚实预期：它在熊/震荡段近似现金（2025-2026 段 -2%），牛段吃到大部分涨幅但回撤砍到 1/4。
    7 月停掉它的原因是"长期无订单"；是否重新启用属于新的 owner 决策，不能由本设计文档推导。
- **配置骨架**（示例，按你风险偏好调）：美股宽基 40% / 长债+黄金 25% / crypto（经 MiniTrend 闸）
  10–15% / 现金及等价 20–25%；月度再平衡 + 各 sleeve 自带趋势闸。

### Sleeve 2 — 卫星：事件 / 被迫流（占 10–15% 资金，风险预算制）

延续你 7 月已确定的研究篮子（current.md 下一步 §2 原文方向），按"谁被迫交易"逐条推进：
1. **宏观事件右侧**（FOMC/CPI/NFP）：FOMC v0.2 已就绪，7/30 canary 就是第一个真实样本。
   每年 ~16 次事件，单次风险 5–10U 起步，赢率不需要高，靠 2R+ 不对称性。
2. **crypto funding/清算被迫流**：极端 funding + 清算级联后的均值回复——被迫方明确
   （被强平者与被费率挤压的杠杆多头），与 L4 不同：单所、taker 可行、日级持有。需新 G0。
3. **TradFi/tokenized 周末-现金时段错位**：证据弱（71%），保留观察，只 alert 不 daemon。
4. 本次 PreEvent-Range 这类**事件前区间 fade** 若 7 月样本可以，可作为事件篮子的常规前菜。

### Sleeve 3 — 研究线（0% 真钱，继续 G0 纪律）

stablecoin 边际流（已过三源 G0）、OI/flow forward 采集继续走：它们是未来替换/加强
Sleeve 2 信号的管道，不承诺产出。任何新候选仍从 G0 开始，latest-vintage 不给资格。

## 四、诚实的收益预期与判据

- **不要预期**："每月正收益""年化 50%"——你的全部证据都否定这种预期在个人条件下成立。
- **合理预期**（基于已消费历史的量级）：组合年化高个位数到低两位数、maxDD 目标 <15%、
  crypto 子仓 maxDD <20%；事件 sleeve 期望为正但方差大，用风险预算硬顶住尾部。
- **成功判据要预登记**：建议以"滚动 12 个月组合收益 > 现金利率 + 4%，且 maxDD<15%"为
  组合级 gate；单 sleeve 用各自既有 gate。失败即缩减该 sleeve，不救援。
- **最大的敌人排序**：过拟合救援 > 成本 > 杠杆 > 信号错误。你的纪律体系已经是同类个人系统里
  最强的部分，保住它比找新信号更值钱。
