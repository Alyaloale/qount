## 0. 核心原则:优化是门后的增益,不是门票

1. **条件化**:每个优化明确挂在一个**宿主**上(H1 的 S1e 混合构型 / H2 的 ETHBTC 线)。
   宿主没过 v0.3 的预注册判生死,挂在它上面的优化**一律不跑**——不允许「基线不过,
   叠优化叠到过为止」,那是多重检验的 garden of forking paths,= 自欺。
2. **唯一救援条款(预注册)**:若 S1e 基线落在中间带(Δ>0 但不满 3/6 年或切换税超标),
   允许**仅用 O-A3(切换税工程)重测一次**——理由:切换税是纯成本工程,降它不是挖信号;
   其余优化(ATR/高斯)是信号侧旋钮,不享受救援资格。一次,不过即收口。
3. **一轮一改,可一键回退**:每个优化独立单测、独立 artifact、对照 = 已合入的上一版,
   带显式退化开关(同 v0.2 §1 的「σ→∞ 退化回基线」哲学)。
4. **v0.2 遗产逐项处置**(不是全盘继承,也不是全盘丢弃):

| v0.2 优化 | v0.4 处置 | 理由 |
|---|---|---|
| ③ ATR 弹性间距 | **复活 → O-A1**(宿主:S1e range 态) | 原版攻「破网尾部」已无意义(混合构型 below-MA 清仓);新版攻「range 态 harvest 效率」,波动率绑定间距的数学(=仓位波动率目标化,线 A L1 同源)仍成立 |
| ① 高斯分配 | **复活 → O-A2**(宿主:S1e range 态) | 原版与「深跌摊薄」的哲学冲突**被宿主解除**:混合构型永远不需要深渊弹药(regime 切换负责逃生),高斯只剩「对 range 持续的下注」这一个风险,可单独 kill-test |
| ② 追踪网格 | **永久关闭** | 它的职能(救踏空)被 S1e 的 uptrend 持有态**完整取代**,且持有是更好的趋势跟随(S1 已证) |
| ④ Tier-1 生息 | **缩水保留 → O-C1** | 宿主变了收益跟着缩水:hybrid 只有 range 态有闲置 U;ETHBTC 线闲置的是 BTC(活期 ~0.1–0.5%,可忽略) |
| ④ Tier-2 永续叠加 | **维持不碰** | v0.2 §5 的四条硬伤一条没变 |

## 2. Track A — S1e 混合构型的优化(宿主:H1 过门)

### O-A0 range 态布网区间规格(必要规格,随 S1e 落地,不算优化)

S1 用的全窗口 min/max 后视镜区间在 S1e 里**不允许存在**(S1e 是要过 S3 的现实构型)。
进入 range 态时的布网规则必须不偷看未来:

```text
center = 进入 range 态当日收盘价
σ_d    = 过去 30 日日收益率标准差
[L,U]  = center · exp(∓ z·σ_d·√H)      z = 2,H = 90(预期 range 持续天数)
step   = 1%(基线,O-A1 再动它)
越界处理:价格出区间但 regime 仍 range → 整体重布(计费、计次);regime 切换 → 按切换规则。
```

读数:重布频率 × 重布成本(它是隐性切换税,并入 O-A3 的 tax 统计)。

### O-A3 切换税工程(顺序 1:攻混合构型的最大死因)

S1e 的死法大概率不是「range 态不赚」而是「切换被打脸」。三项措施,各自独立开关:

```text
(a) 不对称滞回:进 range 用 |r90|<15%,出 range 回 uptrend 用 r90>20%
    (回趋势态更难 → 防 r90 在阈值附近抖动来回切;镜像地,range→below 沿用 SMA200+确认)
(b) maker 分批过渡:切换产生的建仓/清仓单先挂 maker 限价,24h 未成交残量 taker 扫尾
    (对照:全 taker 市价切换;读数:切换成本中 maker 占比)
(c) 渐进建格:进 range 后分 3 日各建 1/3 网格——假 range(进后立刻单边)只付 1/3 的税
    (代价:真 range 的头 3 天 harvest 打折;这是显式权衡,回测给数)
```

**kill-test(对照 = S1e 基线版)**:切换税年化 ↓ ≥50%,且 trend 桶的 Δ(grid−hold) 不恶化
(滞回不能让你在真趋势里慢半拍,把省下的税在方向上亏回去)。读数:`switch_count`、
`whipsaw_cost`(切换后 N 日内反向重切的频率 × 成本)、tax 年化。

### O-A1 ATR 弹性间距(顺序 2;v0.2 ③ 的移植版)

```text
仅 range 态生效:base_step = clamp(k_atr · ATR14 / price, 0.5%, 3%)
k_atr 扫 [0.5, 1.5];间距变化 ≥±20% 才触发重布(hysteresis,防逐 bar 抖动)
逻辑:range 态由 |r90| 定义,但波动率在 range 内仍起伏——
  低波段间距收窄(吃细震荡、提高穿越数),高波段放宽(守住 net_per_grid ≥ 0.30% 费后垫)
```

**kill-test(对照 = O-A3 合入后的固定 1% 版)**:range 桶 harvest 年化 ≥ 对照 +1%,
且 maxDD 不升、重布成本不吃掉增益。读数:`net_per_grid` 分布、穿越数、重布次数 × 费。
**不过则回退固定 1%**——v0.2 ③ 的「防接刀」论证在这里**不适用也不引用**(逃生靠 regime 切换)。

### O-A2 高斯分配(顺序 3;v0.2 ① 的移植版,矛盾已解除)

```text
仅 range 态生效:w_k ∝ exp(−(ln P_k − ln center)²/(2σ_alloc²)),σ_alloc 使内 1/3 格 ≈ 70% 资金
σ_alloc→∞ 一键退化回等额(基线可复现)
矛盾解除论证:v0.2 指出高斯「削弱深跌摊薄、与破网抄底冲突」——混合构型下不存在破网抄底,
  below-MA 清仓是唯一逃生门 → 高斯只剩一个风险:「假 range」时密集区一侧被快速吃光。
```

**kill-test(对照 = O-A1 合入后的等额版)**:range 桶风险调整 harvest(Sharpe)显著 ↑,
且「假 range 切换」事件中的损失 ≤ 等额版 × 1.2(预注册上限,超了就回退 uniform)。

## 3. Track B — ETHBTC 线的优化(宿主:H2 过门)

### O-B2 步长 × 费率扫描(顺序 1)

ETHBTC 比价波动率低于 BTCUSDT,1% 步长可能穿越数不足:

```text
step ∈ {0.5%, 0.75%, 1%, 1.5%, 2%} 扫描,BTC 本位年化为目标;
硬约束维持 net_per_grid ≥ 0.30%(0.5% step 时 net 仅 0.35%,贴边 → 必须配 O-B1 加严通过);
借线 A DSR/PBO harness 给「最佳步长」打多重检验折扣,选稳健平台不选尖峰;
滚动窗口验证(前半窗选参、后半窗验证),不全窗口调参。
```

### O-B1 maker fill 压测(顺序 2;= v0.1 S2,对 ETHBTC 加严)

```text
盘口比 USDT 对薄一个量级 → 加严:
  跳空 bar(|open/prev_close − 1| > step)内的成交一律按 taker + 滑点 10bp 计
  (BTCUSDT 的 S2 用 5bp;ETHBTC 翻倍);
读数:required_maker_fill;判生死:≤ 0.9 且 BTC 本位仍正 → 过;需 >0.95 → maker 墙,kill。
```

### O-B5 滤网利用率门(伴随读数,预注册)

ETHBTC 长期下行段会让 SMA200 滤网长期 PAUSED:

```text
读数:全窗口 ACTIVE 时间占比。
判生死:ACTIVE 占比 ≥ 30% 且 BTC 本位年化 ≥ 2%,才值得进 paper——
  即使每格都赚,一年只能玩两个月的系统,生息被稀释到 < 运维成本,诚实放弃。
诱惑拒绝:**不允许**为提高利用率而摘掉滤网(在 −75% 量级的资产上裸跑 long 网格 = 已知死法)。
```

### O-B4 沉淀模式(默认即定,非实验)

`settle_quote`(利润落袋为 BTC):与「BTC 生息层」定性一致。
`settle_base`(积累 ETH)= 隐含看多 ETHBTC,与 H2「无长期漂移」假设自相矛盾 → 不做、不测。

### O-B3 费率工程(live 前一次性,~小时级)

```text
BNB 抵扣 −25%(maker 0.10% → 0.075%):回测已按 0.075% 假设,live 必须真开启;
BNB 持仓敞口诚实记账(几个月手续费用量,敞口小但 mark-to-market 进线 B 账本,不白嫖);
zero-fee 促销对(Binance 偶有)只在 live 时核实,回测一律按 0.075% 保守,不预支。
```

## 4. Track C — 通用(任一线存活即挂)

### O-C2 执行工程(S4 paper 的门票,必做、非可选)

从 v0.1 §4 继承,这里给验收清单(paper 期间逐项打勾):

```text
□ 对账循环:每轮主循环拉真实挂单+持仓 vs 理论网格状态,漂移自动补挂/撤单(幂等);
□ 部分成交:以「格」为最小记账单位,残量挂单跟踪不丢;
□ 断线重连:重启后从交易所状态重建本地账本,不重复挂单、不漏配对;
□ regime 切换时的挂单清理:切换瞬间撤单/建仓的顺序确定性(先撤旧再建新,中途崩溃可恢复);
□ notifier:切换、对账漂移、全局止损触发三类告警必达。
判生死(= v0.1 S4):paper 实现盈利与回测一致、零对账事故,才谈 live(所有者显式决定)。
```

### O-C1 Tier-1 闲钱生息(live 后可选,先验已缩水)

```text
hybrid 线:仅 range 态有等待下方买单的闲置 USDT → 年化贡献 ≈ Earn 利率 × range 态占比 × 闲置比例,
          先验 < 1%/yr。定性:锦上添花,不进任何判生死算术。
ETHBTC 线:闲置资产是 BTC,活期 ~0.1–0.5%/yr → 不值得工程量,放弃。
约束维持 v0.2:只用 Flexible(即时赎回),赎回延迟实测 ≤ 下单容忍窗口才开。
```
