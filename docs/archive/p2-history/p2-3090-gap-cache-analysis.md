## 根本原因分析

### 1. ProcessPoolExecutor配置问题

**3090配置**:
```python
parallel = 10
workers_factor = 3.0
workers_per_process = 3
total_workers = 30
```

**WSL配置**:
```python
parallel = 4
workers_factor = 8.0
workers_per_process = 8
total_workers = 32
```

**关键差异**:
- 3090: 10进程 × 3 workers = 30 workers
- WSL: 4进程 × 8 workers = 32 workers

**影响**: 
- 3090每个进程只有3个workers，无法有效预生成
- WSL每个进程有8个workers，可以充分预生成和缓存

### 2. 批次调度问题

**当前调度**:
1. 10个进程同时训练Episode 1
2. 全部完成后，等待下一批世界生成
3. 30个workers生成10个新世界
4. GPU空闲等待18分钟

**理想调度** (pipeline):
1. 进程A训练Episode 1时
2. Workers预生成Episode 2的世界
3. 进程A完成后立即使用缓存世界
4. GPU无间隙

### 3. 世界复用机制未生效

**WSL机制**:
- Episode 0: 生成256个世界 (146秒)
- Episode 1+: 复用相同世界 (0.39秒)
- 只需重新采样action

**3090机制**:
- Episode 0: 生成世界 (347秒)
- Episode 1: **重新生成世界** (125秒)
- 世界未复用

**可能原因**:
1. Workers不足导致缓存失效
2. 进程间世界共享机制问题
3. batch_worlds参数传递问题
