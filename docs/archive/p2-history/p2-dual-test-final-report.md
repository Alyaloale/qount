## 二、关键发现

### 1. Episode速度加速明显

- Episode 1: 61秒（世界复用）

**加速原因分析**：
- Episode 0: 完整流程
- Episode 1+: 世界复用（time_gen=0）
- Episode 2: torch.compile warm-up完成

### 2. 世界生成复用机制

**观察**：
- Episode 0: 生成新世界（37.5秒）
- Episode 1-2: time_gen=0（世界复用）

**解释**：
```python
# train.py的世界pipeline机制
with ProcessPoolExecutor(max_workers=cfg.workers) as pool:
    pending = [pool.submit(_gen, j) for j in jobs(0)]  # 预生成下一批
    for ep in range(cfg.episodes):
        worlds = [f.result() for f in pending]  # 使用已生成的
        if ep + 1 < cfg.episodes:
            pending = [pool.submit(_gen, j) for j in jobs(ep + 1)]  # 并行生成下一批
```

✅ **这是正确的pipeline设计**，世界生成与训练并行

### 3. 3090 vs WSL对比

| 指标 | 3090 | WSL | 差异原因 |
|------|------|-----|---------|
| Episode 0 GPU训练 | 156.8秒 | 61.3秒 | torch.compile编译开销 |
| Episode 1 GPU训练 | 46.0秒 | 59.9秒 | 3090 compile生效，更快 |
| 总参数量 | - | 8,232 | 相同配置 |

**结论**：
- 3090的torch.compile有初始开销，但启用后更快
- WSL的eager mode稳定但较慢
- 预期3090 Episode 2会更快（~30秒）
