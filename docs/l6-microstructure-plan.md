# L6 微观结构信息边 —— 全程方案

重启线 L6:把信息源换成 **A股 逐笔委托级 Level-2(Wind 三件套)**,攻基本定律
`IR = IC × √BR` 的 **IC 项**,主目标 **T+0 ETF**(可日内回转、免印花税;个股 T+1 大半 alpha
不可兑现)。数据资产见 `memory/ashare-l2-tick-data.md`;全量 ~6TB 在网盘(逐日 × 全市场)。

## 0. 核心重构(来自 Phase 1 实测,2026-06-08)

**可预测性已不是瓶颈。** Phase 1(单日 20260407,15 只 T+0 ETF)实测:

- `micro_price_dev @1m` rank-IC **+0.139**(符号稳 0.93)、`depth_imbalance @1m` **+0.080**(0.87)、
  `@5m` **+0.100**——**真实、符号稳、远超日频 0.05 天花板**。这是项目首次用结构性新数据
  把 IC 真正抬上去(价量日频上 ML 抬不动 = 已证;L2 上数据抬得动 = 已证)。
- **但每个可操作档(≥1m)净收益全负**:`micro_price_dev @1m` IC 0.139 而 gross 仅 ~0.8bp/笔,
  盖不住 T+0 ETF 往返成本(~5–10bp)。大振幅 IC(3s 档 0.30 / 30s 档 0.19)在亚分钟,
  需 co-location = 延迟无关操作者够不着(L4 延迟墙的变体)。

**结论性重构**:`sign(feature)·每根 bar 下注` 是最笨的策略,必然净负。L6 能否成立,
**不取决于再找信号,取决于能否跨过"振幅 < 成本"这堵墙**。两个唯一的合法杠杆:

1. **降成本** → maker/被动执行(吃价差而非付价差),把往返成本从 +10bp 推向可能为负。
2. **抬有效振幅** → **选择性/阈值交易**:只在 `E[移动 | 信号强度] > 成本` 的信号尾部下注
   (Phase 1 在全样本上下注,平均 1bp;强信号尾部可能 5–10bp)+ 净持仓降换手。

延迟我们改不了(慢操作者),所以**亚分钟高振幅区放弃**,全部火力压在「≥1m 的弱振幅 IC
能否靠 选择性 + maker 变成净正」。这是 L6 的生死命门。

## 1. 硬约束与纪律(全程不变)

- research-only;live 关闭;不 forward paper;不碰 `validation_v1`,直到有足够厚的多日 OOS。
- 一轮只改一处、先写单测;本地 unittest → sync-to-wsl → run-wsl-tests → 研究命令 →
  artifact 落 `state/research_runs` → 写回 current.md / update-log.md。
- WSL 是回测真相;Mac 是编辑面。
- 最便宜的证伪优先;每个 Phase 有显式门控,不过则按 §7 诚实退出或固化。
- A股 摩擦显式建模:T+0 ETF only(个股仅做次日弱对照)、涨跌停/停牌、印花税(ETF 免)、
  佣金、冲击、撮合规则(深市价格优先时间优先)。

## 2. 数据工程(6TB 可处理化,横切所有 Phase)

**不把 6TB 搬到 WSL。** 三选一 + 一次性 ETL:

- 优先在 6TB 落地的主机就地处理;否则按需逐日切片(单日 15-ETF ≈ 420MB,30 天 ≈ 13GB 可搬)。
- **一次性 ETL:原始 Wind CSV → 压缩列存(parquet/feather)**,每 标的×日 只留特征所需:
  - 盘口快照(十档,可降频到事件驱动关键帧)+ 衍生 mid/spread
  - 逐笔成交的签名成交量聚合(秒级桶)
  - 逐笔委托/撤单事件(maker 研究用,Phase 4 才需全量)
  预计把 6TB 压到 ~100–300GB,后续重复处理走列存、不再解析 CSV。
- 滚动逐日处理,绝不全量进内存;严格无前视;跨日 purged-CV + embargo。
- universe:先 15 只高流动 T+0 ETF;证明路径后再按容量扩。

## 3. 分阶段路线(每阶段一道门)

### Phase 1 —— IC-vs-horizon 衰减(已完成)
工具:`src/qount/l6_microstructure.py` + 命令 `l6-microstructure-ic-scan`。
判词见 §0。artifact `state/research_runs/l6_phase1_20260407.json`。**单日**,下一步必须跨日复核。

### Phase 2 —— 跨日 IC 稳定性 + 真实成本校准(数据到位后**第一刀**,最便宜)
- 选 ~20–40 个交易日覆盖不同 regime(趋势/震荡/高低波动)。逐日重跑 IC 衰减。
- 度量**跨日**符号稳定性 + IC 分布(均值/标准差/正比例),**取代被 ETF 相关性高估的单日 t**。
- **从 `行情.csv` 实测每标的报价价差分布** + 佣金 → 用经验往返成本替换 5bp 假设。
- 顺带补 `_panel_effective_breadth`(15 ETF 收益面板),量化跨标的相关、修正显著性。
- **门控**:IC 跨日符号稳(如 ≥70% 日同号)且经验成本已知。跨日翻号 → L6 = 单日假象,证伪退出。

### Phase 3 —— 选择性/阈值交易 + 净换手(攻振幅,不需速度)
- 构建**条件边曲线**:`E[前向移动 | 信号分位]` vs 经验成本,找是否存在 ≥1m 的信号尾部
  其 gross 移动 > 往返成本。
- 只在强信号尾部下注 + 连续同号净持仓降换手;复用项目已有 triple-barrier / 成本感知回测。
- **门控**:阈值选择 + 经验成本后的 LS,跨日 Sharpe 正 + DSR/PBO/purged-CV 过。
  taker 路径连强信号尾部都盖不住成本 → taker 证伪,只剩 maker。

### Phase 4 —— maker/被动执行经济学(真正的逃逸,即 L4 的墙)
- 慢操作者捕捉亚分钟振幅的唯一路:被动挂单吃价差。用逐笔委托+逐笔成交重建队列,
  估**成交率**与**逆向选择**(信号说要往不利方向动时你恰好被成交)。
- 关键量:`信号条件 maker PnL = 捕获价差 × 成交率 − 逆向选择`。
- **门控**:跨日扣费 maker PnL > 0。这正是 L4 的 `required_maker_fill` 墙,在 ETF 盘口
  (比加密永续浅、HFT 饱和度可能更低)上重审——可能赢,也可能原样撞墙。

### Phase 5 —— 模型升级 + 组合(Phase 3 或 4 过了才做)
- GBDT 组合 micro_price_dev + depth_imbalance + ofi → 增量 OOS IC/振幅;
  有时序结构再上 TCN/Transformer;AutoML 关在 purged-CV 内、按多重检验上 DSR/PBO 惩罚。
- 跨 ETF 组合:有效广度 + 仓位(DRL 仅在 sizing 层、不产 IC)。

### Phase 6 —— 执行/容量/实盘前(有净正信号才做)
- 非 co-located 真实执行 sim、容量(ETF ADV)、涨跌停/停牌、滑点;T+0 回转机制。
- 全过后才谈 paper;`validation_v1` 留给足够厚的独立多日窗口。

## 4b. L6-daily(主线,2026-06-08 所有者选定)——L2 衍生日线知情流

**日内线(§3 Phase 1–6)暂搁:手续费遭不住**(振幅 < 成本,只有翻 maker 墙才行,先不投)。
主线转向:**用 L2 当日线信息源**——成本无关(日移动 1–3% >> 10bp)、广度友好
(全个股截面 eff-breadth ~7 >> 行业/ETF 1.7)、数据极便宜(日线只要每日聚合,6TB → 小面板)。

**核心区分**:不能把日内信号拿去持有一天(订单流 IC 10–30min 就衰减到 0)。要为日线
**新设计特征**。项目日线已证伪的是券商**粗糙主力净流入**(按成交额分档,反向);我们用
**原始逐笔**重建**真知情流**,质量完全不同,这是它可能赢的唯一理由。

**假设**:逐笔重建的日线知情流特征,在全 A股 个股截面上对**次日/次周**收益的截面 rank-IC,
能过 ~0.06(粗资金流和价量都没过的线)。先验:A股 日线多因子最拥挤,但真知情流 ≠ 粗主力。

**v1 特征(每股每日一向量,全部 L2 衍生、严格无前视、区别于粗主力)**:
- `aggressive_ofi`:主动买−主动卖 量 / 总量(逐笔成交 BS标志,非成交额分档)
- `large_aggr_ofi`:仅大单(当日成交量 p90+)的主动方向不平衡
- `late_minus_early_flow`:尾盘(14:30–15:00)主动流 − 早盘(09:30–10:00)主动流(机构晚动)
- `close_auction_imbalance`:收盘集合竞价(14:57–15:00)净方向
- `cancel_imbalance`:买撤−卖撤 / 总撤(挂单诱导/意图信号;深市撤单在成交文件、沪市在委托文件)

**目标**:次日 close-to-close(及次 5 日)截面收益。**全个股截面**;个股难做空 →
诊断用 top-bottom decile LS,真实交易按 **long-only(top decile vs universe)或股指期货对冲**。

**数据工程(最大红利)**:日线特征 = 每(股,日)一行 → 6TB 原始逐笔经一次 ETL 塌成
~MB 级小面板。ETL 按 (股×日) embarrassingly parallel,输出极小;之后 kill-test 秒级。

**分阶段**:
- **D0(现在,用 20260407)**:写日线特征 + ETL(`l6-daily-features`)+ 单测;在单日全截面
  验证特征分布合理、无前视。产出 day-1 特征面板。**单日不能测预测力**(需 T 特征 → T+1 收益)。
- **D1(多日数据到位,生死第一刀)**:跨日 × 全个股截面 rank-IC + 跨日符号稳定 + DSR/PBO +
  `_panel_effective_breadth`。门控:截面 IC > 0.06、跨日符号稳、广度过线。
- **D2 增量门(关键)**:必须证明 L2 知情流相对「价量动量 + 粗主力资金」基线有**增量 IC**——
  否则只是换皮重测已证伪信号。
- **D3**:long-only / 股指期货对冲组合,扣费(日线成本可忽略但仍计)、purged-CV、跨日 Sharpe。
- **D4**:GBDT 组合 → 有时序结构再上模型;DRL 仅 sizing。
- **D5**:容量/涨跌停/停牌/T+1 → paper(全过 + 厚多日 OOS,`validation_v1` 留到最后)。

**诚实预期**:D1/D2 定生死——真知情流能否过 0.06 且对已知失败信号有增量。成本墙在日线
不存在,广度也够,**这条比日内好走**;风险全在「IC 是否过线 + 是否只是重测拥挤因子」。

## 4. 诚实的预期(日内线)

L6 大概率在 **Phase 3/4** 定生死:~1–3bp(≥1m)振幅能否靠**选择性交易**或**maker 执行**
盖过 ~5–7bp 真实往返成本。**Phase 2(跨日)是最便宜的杀手锏**——单日 IC 若不跨日稳定,
L6 当场出局。上行情形真实存在(IC 确被击穿);现实情形是 L6 需要 maker 执行才成立,
而那是 L4 的墙在(可能更友好的)ETF 盘口上的重演。无论结果,反过拟合 + 成本/延迟诚实
建模的 harness 是固化成果。

## 5. 终局(2026-06-09,所有者授权固化止盈)

L6-daily close_auction 这条线走完了 D0→D4 + 执行线 B,定论与上面 §4 的预判一致:**需要 maker
才成立,撞回 L4 的墙。**

- **D1(52 截面)**:close_auction ETF rank-IC 0.021(t−3.38),广度墙 ~1.85 → 实测仅要求的 0.44×;
  加厚样本让信号回归零、离墙更远。
- **D2**:控制价量后增量 IC 保留 103% —— **确属价量正交的真新信息**(项目首次证实「L2 真知情流
  ≠ 价量」),这是它最有价值的结论。
- **D4**:线性组合 OOS(purged-CV)崩到 ~0/翻负,组合救不了广度。
- **执行线 B(`evaluate_l6_t0_execution`)**:绕开 IR=IC√BR 截面下界,改问日内 T+0 可兑现性。拆解发现
  **收盘竞价买压 → 隔夜跳空续涨(IC+0.045)→ 日内反转(IC−0.029)**,日内 gross +7.6~9.9bp(t>2.4)真实。
  但实测交易尾价差 ~13–14bp → **taker 往返 ~31bp,net −23bp(t−7),taker 死**;竞价撮合(仅佣金)net
  +2.6/+4.9bp 但 t<1.3 不显著。**价差-信号陷阱**:edge 在不流动 ETF、流动品种上信号塌掉 → edge 本质是
  **薄 ETF 流动性提供溢价**,只有 **maker** 拿得走 = L4/§3-Phase4 的墙。

**结论**:close_auction 是项目迄今最干净的信号(真实+显著+价量正交+隔夜/日内结构清楚),但 taker
不可兑现,要拿只能做 maker——而那是已知撞死的墙。**与 §7/L1/L3b/L4 同型固化止盈**:stop investing,
不放宽任何纪律。沉淀=D0–D4 + T0 隔夜/日内分解 + 实测 taker/auction 成本 的反过拟合 harness;
新增特征 `day_open`/`quoted_spread_bps`、命令 `l6-t0-exec-scan`、ETF 重 ETL 基建 `l6_etf_reetl.sh`。
未来若要续:唯一逻辑自洽的方向是 maker 队列经济学(成交率 × 逆向选择),先验=L4 撞死的墙。
