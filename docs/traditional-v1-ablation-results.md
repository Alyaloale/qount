# 📊 Traditional V1 策略: Phase A & B 测试报告

## 一、 Phase A: 代码与口径审计完成情况
1. **统一数据源与代理映射**：在 `build_features.py` 中引入了 `return_63d` 和 `return_126d`。
2. **信号与执行分离**：特征（SMA200、Z-Score、动量）全部使用 1 倍底层资产（QQQ、SMH 等）计算，彻底避免了 3 倍杠杆带来的波动率扭曲和复利损耗。
3. **消除逻辑冲突**：移除了互相矛盾的负 Z 抄底与 SMA200 止损，纯粹用 SMA200 系列做防御，正 Z 做止盈。
4. **统一评价体系**：使用了严格的 **TWR (时间加权收益)** 进行回测计算，隔绝了定投现金流的污染。设定了 **90% BIL + 10% 3x ETF** 的绝对固定风险袖套，所有模块比较都在统一风险水平下进行。

## 二、 Phase B: 模块消融测试 (Ablation Test) 结果
基于 2018 年至 2026 年中期的严苛测试区间（涵盖 2018年末暴跌、2020年熔断、2022年大熊市），各模块累加测试结果如下：

| 模块 (Module) | 规则累加说明 | CAGR (%) | MaxDD (%) | Sharpe Ratio |
|---|---|---|---|---|
| **M0** | 基础：90日Top2轮动 (不加任何过滤) | 8.66 | -10.35 | 1.26 |
| **M1** | M0 + 绝对动量 (90日收益>0) | 6.78 (Δ-1.88) | -10.35 (Δ+0.00) | 1.03 (Δ-0.23) |
| **M2** | M1 + SMA200 价格过滤 | 6.45 (Δ-0.33) | -10.35 (Δ+0.00) | 1.00 (Δ-0.03) |
| **M3** | M2 + **SMA200 斜率>0 过滤** | 5.21 (Δ-1.24) | **-5.87** (Δ+4.48) | 1.01 (Δ+0.01) |
| **M4** | M3 + **正Z(>=1.5)高位减仓** | 4.20 (Δ-1.02) | **-5.00** (Δ+0.88) | **1.15** (Δ+0.15) |

*(注：基础 CAGR 只有 8% 左右，是因为组合中有 90% 的资金强制锁定在无风险资产 BIL 中，这是名副其实的低风险组合。MaxDD 仅有 10% 证明了这一点)*

## 三、 结果分析与下一步建议

### 1. 发现的残酷事实：“简单趋势”不一定有用
根据您的指导原则：“*如果某模块只降低CAGR，却没有显著降低回撤，就删除*”。
*   **M1 (绝对动量>0)** 和 **M2 (价格>均线)** 在这段历史中表现令人失望。它们严重削弱了收益，却**完全没有降低最大回撤**（MaxDD 依然是 -10.35%）。这说明在急跌反弹的市场中，这两个规则频繁导致“卖在底部，踏空反弹”。

### 2. 真实验证了的 Edge：“均线斜率”与“高位止盈”
*   **M3 (SMA200 斜率)**：这是真正的“熊市过滤器”！虽然牺牲了 1.24% 的年化，但将最大回撤从 -10% 直接**砍半**到了 -5.87%。这印证了我们之前的担忧：价格偶尔反抽上 SMA200 但长期均线仍在下行时，往往是“假突破被套”的重灾区。
*   **M4 (Z-Score 止盈)**：高位削减风险确实进一步降低了回撤 (-5.00%)，并显著拉升了夏普比率 (提升至 1.15)。这证明了 Z-Score 作为一个“见好就收”的工具是极度合格的。

### 🚀 下一步 (您的决断)
由于 M1 和 M2 的表现违背了我们的去留原则，我们有两种选择：
*   **选项 A (严格执行原则)**：彻底砍掉 M1 和 M2，直接测试 `M0 + M3 (均线斜率) + M4 (高位止盈)`。
*   **选项 B (保留防守)**：认为 M1 和 M2 是符合常识的必加项，直接带着这套完整的 M4 进行 **Phase C (参数高原测试)**。
